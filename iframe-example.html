ChemSnap Iframe Example

This page demonstrates how to properly embed ChemSnap in an iframe with camera permissions enabled.

Important Note

When embedding ChemSnap in an iframe, you must include the allow="camera" attribute to grant camera access.

Example Iframe with Camera Access

HTML Code Example

<iframe src="https://chem-webcam.netlify.app" allow="camera" allowfullscreen></iframe>

Troubleshooting

If the camera still doesn't work:

  1. Make sure your browser has permission to access the camera
  2. Check that the site is being served over HTTPS (required for camera access)
  3. Try using a different browser (Chrome, Firefox, Safari, etc.)
